Flutter Android dan web. Jalankan dari folder ini:
```
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```
Android: `flutter run -d <device-id>` (lihat `flutter devices`).

Data disimpan dalam memori, kembali kosong setelah aplikasi ditutup atau dimuat ulang.
Tidak ada layanan server atau pengiriman ke instansi nyata.
Sumber lengkap ada di lib/, kerangka platform di android/ dan web/.
